**Extending Flight Information Services Across the Terminal**

INALIX implemented the Flight Information Display System (FIDS) as part of the SOC Airport extension project at Adi Soemarmo International Airport.

The system extends FIDS coverage across the expanded terminal areas, providing passengers with accurate and up-to-date information related to departures, arrivals, boarding gates, and flight status through designated display points.

Through seamless integration with the airport’s existing information infrastructure, the implementation expands reliable passenger information services while supporting efficient operations across the enhanced terminal environment.
