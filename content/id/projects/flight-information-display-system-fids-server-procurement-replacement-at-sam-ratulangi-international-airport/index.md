**Peningkatan Keandalan Infrastruktur FIDS**

INALIX melaksanakan pengadaan dan penggantian server Flight Information Display System (FIDS) di Bandara Internasional Sam Ratulangi untuk meningkatkan keandalan dan performa infrastruktur informasi penumpang.

Pekerjaan mencakup penggantian infrastruktur server eksisting dengan sistem yang telah ditingkatkan untuk mendukung pemrosesan data yang stabil, ketersediaan sistem, serta distribusi informasi penerbangan secara berkelanjutan ke berbagai display FIDS yang terhubung.

Melalui peningkatan infrastruktur ini, sistem FIDS memiliki fondasi yang lebih andal dalam menyajikan informasi penerbangan secara real-time sekaligus mendukung kelancaran operasional bandara sehari-hari.
