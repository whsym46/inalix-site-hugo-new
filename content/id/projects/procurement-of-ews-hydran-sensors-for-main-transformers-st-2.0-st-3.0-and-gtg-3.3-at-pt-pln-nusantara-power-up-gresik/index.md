**Meningkatkan Pemantauan Transformator dan Sistem Peringatan Dini**

INALIX mendukung pengadaan sensor EWS Hydran untuk Main Trafo ST 2.0, ST 3.0, dan GTG 3.3 di PT PLN Nusantara Power UP Gresik.

Sensor Hydran berfungsi memantau gas terlarut dalam minyak isolasi transformator untuk membantu mendeteksi indikasi awal potensi gangguan internal. Informasi ini menjadi salah satu acuan dalam evaluasi kondisi operasional dan perencanaan pemeliharaan.

Melalui proyek ini, INALIX turut mendukung peningkatan kemampuan pemantauan kondisi transformator serta keandalan peralatan pembangkit listrik.
